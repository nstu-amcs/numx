# Нелинейные уравнения

Нелинейное уравнение эллиптического типа представлено [тут](../README.md).

## Метод простой итерации

Для решения полученной нелинейной системы организуем следующий итерационный процесс:

$$
A(q^{(k-1)})q^{(k)} = b(q^{(k-1)})
$$

с условием остановки

$$
R(q^{(k)}) = \frac{||A(q^{(k)})q^{(k)} - b(q^{(k)})||}{||b(q^{(0)})||} < \varepsilon
$$
