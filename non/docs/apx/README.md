# Интерполяция и полиномиальная аппроксимация

## Кубический интеполяционный сплайн

Кубический интерполяционный сплайн $S$ для функции $f$ это функция, удовлетворяющая следующим условиям:

1. $S(x)$ есть кубический полином $S_j(x)$, определенный на интервале $[x_j, x_{j+1}]$ для всякого
   $j = 0,1,\dots,n-1$;
2. $S_j(x_j) = f(x_j)$ и $S_j(x_{j+1}) = f(x_{j+1})$ для всякого $j = 0,1,\dots,n-1$;
3. $S_{j+1}(x_j) = S_j(x_{j+1})$ для всякого $j = 0,1,\dots,n-2$;
4. $S'_{j+1}(x_j) = S'_j(x_{j+1})$ для всякого $j = 0,1,\dots,n-2$;
5. $S''_{j+1}(x_j) = S''_j(x_{j+1})$ для всякого $j = 0,1,\dots,n-2$;
6. $S''(x_0) = S''(x_n) = 0$ (натуральный сплайн).

### Построение

Для построения кубического интерполяционного сплайна для данной функции $f$, условия выше применяются для кубического полинома

$$
S_j(x) = a_j + b_j(x - x_j) + c_j(x - x_j)^2 + d_j(x - x_j)^3
$$

для всякого $j = 0,1,\dots,n-1$. Подробные выражения для поиска коэффициентов можно найти [тут](https://faculty.ksu.edu.sa/sites/default/files/numerical_analysis_9th.pdf).
